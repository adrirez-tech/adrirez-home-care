# ADRIREZ HOME CARE - Sistema de Gestão

Sistema completo de gestão para empresas de higienização e impermeabilização de estofados.

Desenvolvido para **Adriano** e **Anny** (ADRIREZ HOME CARE).

## Recursos
- 📅 Gestão de Agenda e Agendamentos
- 👥 CRM e Cadastro de Clientes
- 💬 Assistente de WhatsApp com 1 Clique (Confirmação, Lembrete 24h, A Caminho, Secagem, Garantia)
- 🔔 Alertas Sonoros e Notificações de Novos Agendamentos para os Administradores
- 📄 Orçamentos & Propostas Comerciais com Impressão/PDF
- 📱 Suporte PWA (Instalável no celular Android e iOS)
- 💾 Backup e Restauração em formato JSON

Consulte [COMO-USAR.md](COMO-USAR.md) para o manual passo a passo.
